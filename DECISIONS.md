# DECISIONS.md — approved deviations & spec-silent choices

Format: date · phase · decision · why.

- 2026-07-02 · P0 · **JUCE pinned to `8.0.14`** — latest stable 8.x tag on the JUCE repo at time of Phase 0.
- 2026-07-02 · P0 · **Toolchain = existing VS 2022 Community 17.14 + its bundled CMake 3.31.6 and Git** — everything the spec requires was already installed; nothing new was added. Builds are driven from WSL by invoking the Windows `cmake.exe`, so compilation is native MSVC exactly as specified.
- 2026-07-02 · P0 · **`Tools/` and `tools/` are the same directory** (NTFS is case-insensitive). The repo uses `Tools/` for render/tests sources *and* for `grant_vst3_write.ps1` + `pluginval.exe`, matching both spellings in CLAUDE.md.
- 2026-07-02 · P1 · **Master gain range −60..+6 dB, −60 displayed as "-inf dB", default 0 dB** — SPEC §10 says "−inf..+6 dB" without a floor; −60 dB is inaudible and keeps the range finite for the slider/automation.
- 2026-07-02 · P1 · **JUCE splash screen left enabled** — disabling it (`JUCE_DISPLAY_SPLASH_SCREEN=0`) is only licensed under AGPLv3 or a paid JUCE license. Needs a user decision on how Lumen will be licensed; until then the default splash stays (it briefly overlays the editor's bottom-right corner).
- 2026-07-02 · P1 · **`juce::OpenGLContext` attachment deferred to Phase 5** (SPEC §2). All drawing already goes through normal `paint()`, so behavior is identical; the context is purely an acceleration layer for the heavy Phase 5 visualizers.
- 2026-07-02 · P1 · **Test voice = polyBLEP saw** (SPEC/PHASES say only "band-limited saw"): naive saw with a 2-sample polynomial correction at the wrap. Good-enough band-limiting for a temporary voice; the mip-mapped wavetable engine replaces it in Phase 2. Velocity maps to level as `0.2 * (0.3 + 0.7 * vel)`.
- 2026-07-02 · P1 · **`lumen_render` writes 32-bit float stereo WAV**; `--analyze` currently emits `peak_dbfs`, `rms_dbfs`, `dc_offset`, `nan_count` (+ `schema_phase: 1`). The remaining SPEC §18 metrics land in Phase 2 with the real engine.
- 2026-07-02 · P1 · **Phase 1 editor is a placeholder**: header + the 8 frozen parameters and master gain as labelled knobs, SPEC §14 palette, 1040×660 resizable 70–200% with fixed aspect. Full Play/Deep views are Phase 5.
- 2026-07-02 · P2 · **Basic table layout**: pure sine/triangle/saw/square at frames 0/21/42/63, linear harmonic-domain crossfades between them, everything in sine phase so morphing never cancels. "Saw" in the acceptance renders = morph 42/63 ≈ 0.6667 (`lumen::factory::kBasicSawMorph`).
- 2026-07-02 · P2 · **PWM table sweeps duty 50%→95%**; the pulse's DC term is dropped (all factory tables are DC-free). **Harmonic Rise** uses saw-style 1/h amplitudes (frame f = harmonics 1..f+1). **Formant** = two log-space Gaussian peaks (centers 2→24 and 6→90, σ 0.35, second at 0.6 amplitude) over a faint 1/h^1.5 bed so early frames keep a fundamental.
- 2026-07-02 · P2 · **Frame normalization**: each frame peak-normalized via its level-0 peak; all mips of a frame share that one factor so mip crossovers stay seamless.
- 2026-07-02 · P2 · **`Image` table choice already exists in the APVTS** (keeps the choice parameter's normalized mapping stable forever) and resolves to Basic until Lens lands in Phase 6.
- 2026-07-02 · P2 · **Unison law**: lanes spread evenly across ±detune cents; blend crossfades a center-weighted triangle profile against its inverse, floored at 0.05 (avoids silence/div-by-zero at unison 2 + blend 0); gains normalized by the **amplitude sum**, so unison can never exceed one lane's coherent peak (this is why the unison-8 gate passes with margin; revisit toward power normalization post-v1 if unison feels quiet). Width pans lanes ±offset·width, equal-power.
- 2026-07-02 · P2 · **Phase randomize defaults ON** (both oscs). All "randomness" = xorshift64*/xorshift32 PRNGs seeded with fixed constants at `prepare` — renders are bit-deterministic; no `rand()`/`time()` in the Engine.
- 2026-07-02 · P2 · **Velocity → amplitude linear** (vel/127). Curves can come later via the matrix.
- 2026-07-02 · P2 · **Envelope shapes**: attack = x^p, p = 2·3^(−curve) (default x², measured time-to-90% ≈ −5%, inside the ±10% gate); decay/release remaining = (1−x)^q, q = 3^(−curve) (default linear → −60 dB at 0.999·T); releasing voices end below −90 dB. Envelope times update at block rate (an increment change mid-stage can't click).
- 2026-07-02 · P2 · **Resonance mapping Q = 0.5·24^res**, k floored at 1/12. **LP24's second cascaded stage runs fixed Butterworth damping (k = √2)** so its resonance peak matches LP12 instead of doubling in dB. **BP12 output is k·v1** (unity peak gain).
- 2026-07-02 · P2 · **Drive compensation is measured at `prepare`**: one sine cycle at −12 dBFS through tanh(10^(dB/20)·x) for each dB 0..24, RMS ratio stored in a 25-entry table the voice interpolates. Small signals keep loudness; pushed signals saturate without a level jump.
- 2026-07-02 · P2 · **Sub**: tracks Osc A semi+fine pre-unison-detune (SPEC §5); polyBLEP square, naive triangle (1/h² harmonics, negligible aliasing for a sub), exact sine. **Noise level is a dB parameter** (−60 = off .. 0 dB) because SPEC §13's chroma mapping is written in dB; pink = Paul Kellet economy filter.
- 2026-07-02 · P2 · **Filter mode defaults to LP24** (warm classic-subtractive default; spec names no default).
- 2026-07-02 · P2 · **Smoothing**: all continuous engine params via 20 ms SmoothedValues. Morph/level/sub/noise/cutoff/res/drive/env-amount become per-sample buffers; pitch (fine/detune) and pan/width/blend are smoothed then linearly ramped across each block inside the voice (per-sample exp2 would be wasted cost; the ≤block-length ramp of an increment is inaudible).
- 2026-07-02 · P2 · **Harness envelope metrics** ride a per-period peak grid with interpolated crossings; the acceptance timing runs use MIDI 93 so one analysis window (one period, 0.57 ms) is ≤6% of the shortest 10 ms gate. Attack = time to 90% of peak; release = note-off to −60 dB.
- 2026-07-02 · P2 · **--bench chord** = C2 G2 C3 G3 C4 E4 G4 C5, vel 100, held 8 s of 10. Bench peak lands above 0 dBFS pre-limiter by design (float WAV; limiter arrives in Phase 4).
- 2026-07-02 · P2 · **Voice stealing** (quietest-releasing, else oldest) retriggers envelopes from their current level (declick) and keeps the stolen voice's filter state; only fresh voices reset the filter.
- 2026-07-02 · P3 · **Shared range table**: modulation combines in normalized space (SPEC §9), so `Engine/ModDestinations.h` holds one {min, max, skew-centre} table per destination that both the engine's normalize/denormalize and (by convention) Parameters.cpp's NormalisableRanges follow — host mapping and engine mapping cannot drift apart.
- 2026-07-02 · P3 · **Destination set** = every continuous engine parameter (36: filter ×5, osc ×7 each, sub/noise levels, env ADSR+curve ×3). **Macros are excluded as destinations** (they're sources; macro-modulating-macro recursion parked). `delayMix`/`reverbMix`/`masterGain` become destinations in Phase 4 when the engine consumes them.
- 2026-07-02 · P3 · **Application rates per SPEC §9**: global sources (macros, wheel, aftertouch, bend, mono LFOs) are combined per block and land on the existing 20 ms smoothers; poly sources (envs, poly LFOs, velocity, keytrack, random) are combined per voice per block and linearly ramped across the block (per-sample scratch overrides for buffered destinations, start/end shifts for block-ramped ones). Poly source values are sampled at block start — modulation trails its source by ≤ one block (~10 ms), which is what keeps it click-free.
- 2026-07-02 · P3 · **Macro mapping semantics**: {targetParam, min, max} contributes an additive normalized offset `min + (max−min)·macroValue` under the same clamp rule as matrix slots (min = offset at macro 0). Additive keeps macros composable with the base knob and the matrix.
- 2026-07-02 · P3 · **LFOs are bipolar −1..+1**; poly retrigger restarts at the phase-offset parameter; fade-in applies to poly mode only (a free-running mono LFO has no meaningful fade anchor). S&H draws from seeded xorshift32 per LFO instance — fully deterministic. Sync divisions ordered straight/dotted/triplet per base (24 choices), default 1/4.
- 2026-07-02 · P3 · **Source scaling**: velocity, wheel, aftertouch, envs, macros = unipolar 0..1; LFOs, pitch bend, random-per-note = bipolar −1..+1; keytrack = (note−60)/64 clamped to ±1.
- 2026-07-02 · P3 · **Pitch bend now bends pitch** (hard-wired ±2 semitones, smoothed; the 0–24 range setting arrives with the settings panel) *and* is a matrix source.
- 2026-07-02 · P3 · **Matrix/macro state lives in ValueTree children** (`MODMATRIX`/`MACROS`) of the APVTS state with string tokens for source/dest (survives enum growth); published to the audio thread via an 8-deep round-robin pool + atomic pointer swap (no locks; a stale read would need 8 edits inside one block render).
- 2026-07-02 · P3 · **Env-time modulation is block-rate** (attack/decay/sustain/release/curve): only the segment increment changes mid-stage, which cannot click; sustain steps at ≤10 ms resolution are accepted for v1.
- 2026-07-02 · P3 · **Harness metrics**: `--measure-mod` measures modulation rate as the autocorrelation peak of the spectral-centroid trajectory (Hann 2048/hop 256), and `zipper_ratio` = max/median of per-10 ms first-difference peaks on a sine-voice render (smooth sweep ⇒ ~1, parameter steps spike it).
- 2026-07-02 · P3 · **Temporary matrix panel**: 24 plain rows (enable / source / destination / depth) writing straight into the ValueTree; macro mapping lists are harness-and-preset-only until the real macro UX (Phase 5/7).
- 2026-07-02 · P4 · **FX bus lives in the Engine** (`FxChain`, owned by `SynthEngine`, runs after the voice sum) so `lumen_render` exercises the full SPEC §10 path. Master gain moved from the processor into the chain (spec order: limiter → master gain → meter); the processor now only reports latency (`setLatencySamples`).
- 2026-07-02 · P4 · **Per-effect bypass = 20 ms smoothed dry/wet crossfade** whose dry leg is bit-exact (`out = in + mix·(wet − in)`), so the all-bypassed chain nulls at −144 dBFS (measured). Effects keep writing their delay lines while bypassed — re-enabling is instant and click-free. Defaults: drive & chorus OFF, delay & reverb ON (the frozen `delayMix 0` / `reverbMix 0.12` defaults keep init silent/subtle).
- 2026-07-02 · P4 · **Drive**: ±6 dB tilt = one-pole low/high split at 800 Hz applied **pre**-tanh (tone shapes what saturates); loudness compensation reuses the measured −12 dBFS-sine RMS table, now shared as `FxChain::measureTanhCompensation` with the filter drive.
- 2026-07-02 · P4 · **Chorus**: both lines centred at 13.5 ms, ±6.5 ms · depth (spec's 7–20 ms window), right LFO in quadrature (+90°), cubic Hermite interpolation, linear dry/wet.
- 2026-07-02 · P4 · **Delay**: sync shares the LFO division table (default ON, 1/4); synced times beyond the 2 s buffer clamp to 2 s (4/1 at 120 BPM would be 8 s). Time changes glide through a 100 ms smoother → tape-style pitch swoop instead of clicks (also what delay-time modulation sounds like). Ping-pong: mono input feeds L, feedback crosses L→R→L. Damping = one-pole LP (1–16 kHz) inside the feedback path.
- 2026-07-02 · P4 · **Reverb**: `juce::dsp::Reverb` run wet-only with `wetLevel = 1/3` to cancel JUCE's internal 3× wet scale; dry/wet is our own linear mix so `reverbMix` behaves sanely as a mod target.
- 2026-07-02 · P4 · **Limiter** is custom lookahead (not `juce::dsp::Limiter`, which has no lookahead): per-sample required gain → sliding-window minimum → 80 ms one-pole release → boxcar average over exactly the 72-sample (1.5 ms) window. The math guarantees peak ≤ ceiling by construction; a final clamp backstops it. Gain is exactly 1 below the ceiling → bit-transparent (measured −144 dBFS diff). Window min is brute-force (72 samples ≈ 3.5 M ops/s — irrelevant; bench 49× realtime).
- 2026-07-02 · P4 · **+14 FX mod destinations** (append-only): delay/reverb mix, master gain, drive amount/tone, chorus rate/depth/mix, delay time/feedback/damp, reverb size/damp/width. FX destinations are **global-only** — poly-source routings (envelopes, poly LFOs, velocity…) to them are inactive in v1 because the FX bus has no per-voice identity. Delay-time modulation is ignored while sync is on (the division wins).
- 2026-07-02 · P4 · **Meter tap** = per-block peak/RMS struct on the FxChain (`SynthEngine::meterLevels()`); the SPEC §10 lock-free FIFO to the UI arrives with the Phase 5 meter widget.
- 2026-07-02 · P4 · **Harness**: `--no-fx` renders the pre-FX voice sum; `--analyze` trims the 72-sample FX latency before timing metrics (attack/release stay aligned with note events); `--measure-echo` reports echo spacing via 1 ms envelope onsets (interpolated 25 %-of-peak crossings, median of gaps). Default-patch `release_ms_measured` now reads ≈ 0.94 s because the default reverb tail passes −60 dB after the 200 ms envelope — use `--no-fx` (reads 199 ms) or `reverbEnabled=0` for envelope timing work.
- 2026-07-02 · P5 · **Inter 4.1 static TTFs (Regular/Medium/SemiBold) embedded via BinaryData**; the SIL OFL license text is committed at `Assets/Fonts/InterLicenseOFL.txt` *and* embedded alongside the fonts, satisfying SPEC §14's "verify the license file ships with it".
- 2026-07-02 · P5 · **Live mod-arc values are block-rate**: the engine publishes, per block, the final normalized value of every mod destination (base + global matrix + macros + the *newest active voice's* poly sums) through an atomics struct (`Engine/UiTap.h`). Arcs/visualizers show the newest voice, not a per-voice fan-out; values freeze at their last state when the host stops calling processBlock.
- 2026-07-02 · P5 · **UI resizing = one fixed 1040×660 layout scaled by an AffineTransform** (70–200 %, aspect locked). All layout code is in base pixels; text/vector art scale crisply through the transform.
- 2026-07-02 · P5 · **OpenGL context attached in normal runs; skipped for `--screenshot`/`--check-params`** (`LumenAudioProcessorEditor::disableOpenGL`). All drawing is plain `paint()` so both paths are pixel-identical by construction (SPEC §2); snapshots always use the software renderer.
- 2026-07-02 · P5 · **Shift = fine drag** is implemented as JUCE velocity-mode swell on the Shift modifier (slow mouse ≈ pixel-precise) rather than a literal ×0.1 scale — smooth mid-drag transitions, no value jumps.
- 2026-07-02 · P5 · **Right-click knob menu** ships the modulation half of the SPEC §14 contract now (list/add/edit-depth/remove slots, reset-to-default); *MIDI Learn / Clear MIDI* items are present but disabled until Phase 7. Macro *mapping lists* (min/max per target) remain preset/harness-editable only; macro modulation still shows in the knob arcs.
- 2026-07-02 · P5 · **Drag-drop modulation** grabs the first fully-free matrix slot (else the first disabled one) and creates it with depth +0.25. Footer grab handles cover Env 1–3, LFO 1–3, Macro 1–4; the MIDI-ish sources (velocity, wheel, aftertouch, bend, keytrack, random) are reachable via the right-click "Add modulation" menu instead of chips.
- 2026-07-02 · P5 · **Play-view context visualizer**: wavetable stack of Osc A; Osc B's stack when only B is enabled; output scope when both oscs are off. The image view takes over in Phase 6.
- 2026-07-02 · P5 · **Preset strip and Lens card are placeholders** ("Init", arrows disabled / drop-zone text) until Phases 7 and 6 respectively.
- 2026-07-02 · P5 · **On-screen keyboard → engine goes through a lock-free FIFO** on the processor (message thread writes, audio thread applies at block start). Incoming hardware MIDI does not light the on-screen keys in v1.
- 2026-07-02 · P5 · **Frame/dropout instrumentation**: HUD toggles with the `H` key; while on, the editor forces full-window repaints at 60 Hz and measures the whole paint pass (worst-case full redraw). "Dropout" = a `processBlock` whose wall time exceeds its real-time budget, measured with two high-resolution tick reads per block (userspace counter read — accepted RT practice). `Lumen.exe --stress N` automates the Phase 5 gate: real WASAPI device, held 8-note chord, 6 random continuous-parameter jumps per frame at 60 Hz, JSON stats, exit 0 only if avg ≤ 16.7 ms and dropouts = 0. `masterGain` is excluded from wiggling (hearing protection); `--check-params` prints unreachable APVTS parameters as JSON.
- 2026-07-02 · P5 · **Envelope editor time axis**: segment widths = 0.05 + 0.9·√(t/tmax), normalized against a fixed 0.30 sustain shelf — short times stay grabbable, breakpoint drags invert the same mapping. Filter node drag: x = cutoff (log), y-delta = resonance.
